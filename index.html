03

Türkçe veya İngilizce arayüzü kullan; açık, koyu ya da sistem temasını seç. Pencere, ekranın kullanılabilir alanına göre boyutlanır.

Üç adımda kullanmaya başla

1

Paketi çıkar

GitHub Releases sayfasından Windows x64 ZIP paketini indir. ZIP'in tamamını bir klasöre çıkar; EXE, Fido.ps1 ve FIDO-LICENSE.txt birlikte kalsın.

2

Dosyanı seç

Uygulamayı aç. Ürün, sürüm, mimari ve dosya dili seçeneklerini belirle. Gerekirse arayüz dilini ve temayı değiştir.

3

İndirmeyi başlat

“Dosyayı indir” düğmesine basıp kaydetme konumunu seç. İndirme tamamlandıktan sonra dosyayı amacına uygun şekilde kullan.

Kaynaklar ve merak edilenler

Dosyalar nereden indiriliyor?

Uygulama desteklenen Microsoft yayın adreslerini kullanır. Windows ISO bağlantılarını çözümlemek için açık kaynaklı Fido bileşeninden yararlanır. PowerToys dosyaları Microsoft'un GitHub yayınlarından alınır. ISO dosyaları geliştiricinin sunucusunda yeniden barındırılmaz.

Yeni Windows sürümleri otomatik eklenir mi?

Windows 11 ve Windows 10 için Microsoft'un herkese açık ISO sayfasındaki sürüm bilgisi okunmaya çalışılır. Yeni sürümün görünmesi, Microsoft'un ISO'yu desteklenen sayfa akışında sunmasına bağlıdır. Her Insider veya Windows Update sürümü bu kapsama girmez.

Uygulama Microsoft tarafından mı geliştirildi?

Hayır. Windows ISO Downloader, Bünyamin Kaya tarafından geliştirilen bağımsız bir uygulamadır. Microsoft ile resmî bağlantısı bulunmaz.

Bir indirme çalışmazsa ne yapmalıyım?

Yayın adresleri veya Microsoft'un sayfa yapısı değişebilir. Seçtiğin ürün, sürüm, mimari ve gördüğün hata mesajıyla GitHub üzerinden hata bildirimi yapabilirsin. Kişisel bilgilerini ve lisans anahtarlarını paylaşma.
